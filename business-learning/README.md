# 商务商业：理解价值、交易、经营与现金

[三个领域共同导航](../product-learning/README.md) · [系统知识正文](knowledge.md) · [经营判断与误区](design.md) · [运营推广](../growth-learning/README.md)

本主题面向中国大陆市场，覆盖实体商品、数字产品与各类服务，兼顾个人消费者、企业、政府及事业单位客户，适用于线上、线下、全国和区域经营。这里讲通用经营机制，并说明行业、地区、主体和交易方式怎样改变结论；“通用”不意味着每种业务采用同一种盈利模式、渠道或资质。

采用 **知识正文 → 必要的指定资料 → 判断与案例** 的阅读方式。不设置练习、作业、阶段验收或固定学习时长，也不把读完全部内容设为开始做产品的门槛。可以先获得整体认识，再按眼前经营问题深入。

## 2. 怎样选择阅读深度

先读正文第 1～5 节，建立价值、价格、成本、利润与现金的联系；第 6～9 节帮助理解成交、交付、组织和责任。外部资料用于补原理与核对适用条文，正文已经解释必要概念，不要求用链接替代阅读。

| 经营情境 | 最影响判断的部分 |
| --- | --- |
| 实体商品、零售、制造 | 产品成本、渠道价格、库存和退货、采购与质量、物流、资金周转 |
| 到店、到家、专业服务 | 服务范围、人工与产能、预约和峰谷、预付款、履约质量、投诉与复购 |
| 数字产品、软件、内容 | 授权与订阅、持续服务成本、免费边界、客户批次、数据、取消与退款 |
| 企业客户与项目服务 | 决策链、全周期报价、定制范围、采购、验收、信用、账期与续约 |
| 政府与事业单位采购 | 采购制度、公开文件、资格、预算、履约和验收；适用目录、限额与当地规则 |
| 平台、经销、加盟、联营 | 谁是交易主体、谁承担货权和履约、分账、规则权、终端动销、区域和退出 |
| 全国扩张与区域经营 | 地理覆盖、交付半径、当地供需、渠道密度、跨区域管理及地方行业要求 |

## 3. 指定资料与阅读范围

来源核对于 **2026-09-30**。国内制度以现行官方文本为主；外国教材只解释经济、经营和谈判方法，不作为国内登记、税务、劳动或交易规范。官方网页的发布时间可能早于修订时间，应同时看正文版本与施行日期。

## 4. 通用知识的边界

国内不同地区的购买力、渠道密度、租金、劳动力、物流及采购规则会改变经营结果；港澳台、跨境进出口和境外经营需使用对应法域的资料。食品、医疗、金融、教育、运输、建设、互联网信息服务等行业还需核对主管部门许可、强制标准及特别规则。本主题提供理解和查证入口，不形成覆盖每个行业的资质清单。

商业判断必须与[产品](../product-learning/knowledge.md)的客户价值、[运营推广](../growth-learning/knowledge.md)的触达和关系维护相互解释：成交取决于价值与交易条件，盈利取决于交付和成本，能持续经营取决于现金、组织与责任。多类型的取舍与误区见 [design.md](design.md)。
