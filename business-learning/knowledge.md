# 商务商业知识：从客户价值到可持续经营

[阅读导航与来源](README.md) · [经营判断与误区](design.md) · [产品知识](../product-learning/knowledge.md) · [运营推广知识](../growth-learning/knowledge.md)

商业是让价值生产、交易和交付持续成立的安排。产品回答“客户需要什么”，运营推广帮助客户发现、选择和持续获得价值；商业还要回答“谁付款、谁承担成本和风险、各方何时收到钱、组织能否兑现承诺”。有销量、能盈利、现金充足是三个相关但不同的状态。

本页面向中国大陆的商品、服务、数字产品及多方平台，兼顾 ToC、ToB、ToG、线上线下与区域市场。概念可以通用，行业约束需要分支判断。所有算例均为**虚构教学数据**，币种为人民币，不能视为真实价格、利润水平、税务优惠或市场预测。

## 1. 经济与竞争：理解需求、资源与市场力量

### 1.1 需求是有条件的选择

需求包含需要、购买意愿、支付能力与可获得性。“大家都需要健康”不足以证明会购买某项服务；价格、时间、信任、交通和替代办法都会改变实际选择。市场范围应明确产品类别、客户、地区、时期与渠道，不能用全国行业产值直接预测一家门店销量。

- **需求量变化：** 其他条件大致相同，价格改变引起购买数量变化。
- **需求变化：** 收入、偏好、人口、替代品、互补品、季节或预期变化，使同一价格下的购买量改变。
- **供给变化：** 原料、人工、技术、产能、物流和经营限制改变了可交付数量与成本。
- **市场均衡：** 在模型中需求量与供给量相配的状态；现实存在信息差、调整时间、平台规则和制度约束，成交价不必快速趋于单一价格。

替代品帮助客户完成相似目标，可能来自不同品类；互补品一起提高价值。汽车与公共交通可以替代，汽车与维修服务互补。企业采购中“继续人工处理”和“不做这件事”也是替代。经营者真正面对的是客户的全部可行选择。

### 1.2 价格弹性决定变化幅度

价格弹性描述价格相对变动时，购买数量相对变化的敏感程度。通常替代多、占预算高、购买可推迟、比较方便的商品更敏感；急需、低预算占比或切换难的产品可能较不敏感，但具体人群和时期会改变结果。[原理来源](https://openstax.org/books/principles-microeconomics-3e/pages/5-1-price-elasticity-of-demand-and-price-elasticity-of-supply)。

降价会同时改变单件收入、销量、履约成本、客户结构和未来价格预期。收入增加不能直接推出利润增加；产能已满时，低价还可能挤走更高贡献订单。收入弹性、替代品的交叉影响和互补品价格，帮助解释消费升级、替代与连带销售，但不能拿其他行业的弹性当自己的参数。

定价判断还受信息不对称影响：客户事前难评估装修、医疗或咨询质量，经营者更了解交付过程。透明范围、可验证资质、样例、质量保障和售后能降低不确定性；虚假承诺和刻意隐藏费用会放大交易成本与长期不信任。

### 1.3 边际、机会成本与沉没成本

**边际**是增加或减少一小单位活动带来的变化。例如多接一单需要多少新增材料、工时与占用，新增贡献是否值得。总平均成本帮助判断整体可持续性，边际分析帮助判断下一单；二者不能互相替代。

**机会成本**是选择某方案时放弃的最佳可行替代的价值。老板没有领工资不表示时间免费；店面拿来做自营，可能放弃可获得的租金。**沉没成本**是已经发生且无法收回的投入，不能仅因“已经花了很多”继续亏损；未来仍要支付的维护、违约、退款和退出成本则继续影响选择。[原理来源](https://openstax.org/books/principles-microeconomics-3e/pages/2-1-how-individuals-make-choices-based-on-their-budget-constraint)。

长期决策要看到边际成本台阶：多一单可能不用加人，多一百单需要第二班、设备或仓库。短期空闲容量下的低价订单可能有贡献，长期全部订单按这个价格销售却无法覆盖固定能力。利润也要区分会计结果与扣除资源机会成本后的经济收益。

### 1.4 价值链与议价权

价值链包括研究、设计、原料、制造、配送、营销、交易、安装、使用和售后，服务业则包括获取客户、方案、人员排班、履约和后续支持。价值产生在哪里、利润被谁获取、风险落到谁，是三个问题。

| 影响议价权的因素 | 经营含义 |
| --- | --- |
| 替代与集中度 | 客户或供应商选择少，关键一方更容易影响价格、账期与规则 |
| 差异化与信任 | 可靠质量、独特能力和声誉减少纯价格比较；需要兑现和积累 |
| 切换成本 | 重新培训、迁移数据、改设备或重建供应关系产生实际成本；不等于设置不合理退出障碍 |
| 信息和渠道 | 能接触终端需求、掌握质量事实或拥有稀缺触达能力的一方更能协商 |
| 资产专用性 | 为某客户专门投入设备或定制后，退出更难，合同及补偿安排更关键 |

上下游利润不能简单相加看作自己的可获得利润；渠道可能承担库存、信用、售后和终端维护。选择自营或外包、直销或经销，要同时比较能力、控制、投入与风险。

### 1.5 竞争结构与可持续优势

完全竞争、垄断竞争、寡头与垄断是理解市场的模型。实际竞争还受区域、品类、标准、品牌、渠道、法规和相邻替代影响。局部商圈与全国电商即使卖相同商品，也可能面对不同的竞争结构。

持续优势常来自低成本流程、有效规模、品牌信任、专利或秘密、难复制的供应链、渠道密度、学习曲线和网络效应。网络效应指参与者增加使其他参与者得到更多价值；用户多但彼此不增加价值，不自动构成网络效应。规模经济是一定范围内平均成本下降，范围经济是共享资源经营多类业务更节约；管理复杂和服务半径也会造成规模不经济。

“护城河”要说明优势的机制、复制所需代价、维持成本和衰减条件。领先上线、暂时便宜、大额补贴或依赖某平台流量，可能只是短期优势。优势建设还需遵守竞争规则，市场力量并不授权垄断协议、商业贿赂或侵害客户权益。

### 1.6 宏观、行业与区域环境

经济周期、就业、收入、物价、利率、汇率、人口、城镇结构、技术和产业政策，会通过客户预算、采购节奏、原料、融资与供应影响业务。消费品可能受可支配收入和消费预期影响，设备与企业服务常受客户投资和预算周期影响，区域服务还受商圈人口、产业与交通影响。

| 环境变化 | 传导机制与边界 |
| --- | --- |
| 通胀与价格变化 | 影响原料、人工、租金及购买力；企业能否同步涨价取决于竞争和需求，指数涨幅不等于自己的成本涨幅 |
| 利率与融资条件 | 改变借款代价、客户投资与赊销机会成本；政策利率不等于具体企业能获得的贷款利率 |
| 汇率 | 影响进口设备、原料、出口、外币软件与服务采购；纯国内销售也可能通过供应链受到间接影响 |
| 就业、收入与景气 | 影响支付能力、信心、预算及人员供需；全国变化不能直接代表具体人群与商圈 |
| 政策、标准与技术 | 改变准入、采购、需求与成本；需分清正式生效、过渡、地区范围及行业条件 |

GDP 看一定范围的经济产出，CPI 看居民消费品和服务的价格变化，PPI 看工业产品出厂价格变化，调查失业率看规定调查口径下失业人口占劳动力的比例。统计范围、现价/不变价和同比/环比需要分清；全国均值和行业增长不能直接代替局部客户预算与自己的收入预测。[统计局价格指标解释](https://www.stats.gov.cn/sj/ndsj/2016/html/zb05.htm)、[调查失业率定义](https://www.stats.gov.cn/zs/tjws/zytjzbqs/tcsyl/202409/t20240910_1956360.html)。

## 2. 商业模式：价值怎样变成交易与收入

### 2.1 客户角色和价值流

使用者、付款者、选择者、受益者、审批者可能不同。个人买家也可能替父母孩子购买；企业用户需要服务但预算由部门负责人掌握；政府采购可能还有预算、采购、使用与验收部门。把“用户喜欢”解释为“有预算且能采购”会误判交易难度。

一个完整模式需要说明：客户获得什么结果，提供者如何生产和交付，通过什么渠道交易，按什么收费，关键资源与伙伴是什么，成本和风险如何分配。品牌方、经销商、平台、服务商与金融机构可能同时参与；信息流、货物/服务流、资金流与责任不一定走同一条路径。

### 2.2 常见模式及约束

| 模式 | 收入来源与适用机制 | 主要约束 |
| --- | --- | --- |
| 商品销售 | 转移商品，单件或批量收费；适合标准化商品与可控供应 | 库存、物流、退货、质量、渠道价差、资金占用 |
| 项目或专业服务 | 按范围、里程碑、工时或交付成果收费 | 销售周期、范围变更、人员与产能、验收、账期 |
| 持续服务与订阅 | 按期提供持续价值、使用权或服务能力 | 持续履约、续约、成本变化、取消与预收义务 |
| 按量或按次 | 用量与价值/成本能被客户理解并计量 | 预算可预期性、计量争议、峰值和失败成本 |
| 租赁 | 收取一段时间的资产使用对价 | 资产投入、利用率、维修、损坏、收回与残值 |
| 授权、内容与知识产权 | 许可某项权利使用，按期间、地区、数量或用途收费 | 授权范围、权属、侵权、更新与维护边界 |
| 中介、佣金与平台 | 为交易撮合、分发、支付或保障收取费用 | 双边供需、信任、安全、交易责任和规则执行 |
| 广告与赞助 | 第三方为接触特定受众或关联价值付费 | 流量质量、广告交付、品牌安全、用户体验 |
| 经销、加盟、联营 | 货品价差、授权、管理服务或经营分成 | 终端动销、支持责任、品质控制、区域冲突、退出 |
| 设备加耗材/服务 | 首次设备交易连接后续耗材、维护或服务 | 持有成本、兼容性、服务能力、客户选择及竞争边界 |

免费增值、补贴和促销是跨模式的安排。免费部分必须由其他贡献或可承担预算支持；赠品、售后、安装和运费也属于承诺。套餐捆绑可以降低选择成本与提高完整价值，也会扩大交付范围和纠纷面。

### 2.3 经营模型和收入质量

销售额取决于可接触需求、购买比例、数量、价格和复购；服务还受工时、座位、设备或交付半径约束。市场总量只是背景，实际可获取收入受渠道能力、竞争、产能和销售周期限制。

高质量收入通常更可重复、可收回、客户集中风险更低、履约可控且贡献清楚。“经常性收入”仍可能依赖难续约客户；少数大客户带来大合同，同时带来定制、集中度和回款风险。补贴、融资和借款带来的现金需要与客户收入分开。

增长来源包括新客户、频次、客单、复购、扩展产品、价格和市场覆盖；每一项可能相互影响。产品组合既可共享渠道和能力，也可能蚕食旧产品、增加库存与管理复杂度。第二条业务要看资源和客户协同，不只看“这个市场也很大”。

## 3. 定价与渠道：客户支付和企业所得

### 3.1 价格、价值与总持有成本

成本加成帮助识别成本约束，竞争定价反映替代，价值定价关注客户得到的结果及支付意愿。三种视角应一起看：有成本不代表客户接受，有价值不代表全部价值可以由卖方拿走，有竞品价格也不意味着成本和服务相同。

客户总支出还包括安装、运输、培训、维护、耗材、时间、风险和退出。ToB 报价常需要解释总拥有成本与预期收益；要区分实测改善、合理估计和销售承诺，不能把潜在收益全部保证给客户。

价格表达须明确销售单位、规格、范围、期限、含税与否、运费、安装、售后、超额、续费、取消和退货。报价不完整会在付款或交付时变成争议；更便宜的“起价”不代表完整需求更便宜。

### 3.2 毛利率、加价率与渠道价差

以下以同口径不含税金额为例，销售成本范围固定，避免把不同利润层级混在一起：

```text
毛利 = 营业收入 - 营业成本
毛利率 = 毛利 ÷ 营业收入
加价率 =（售价 - 对应成本）÷ 对应成本
价格折扣率 =（原价 - 折后价）÷ 原价
销售口径贡献 = 净销售收入 - 约定范围内的可变成本
```

**虚构例：** 成本 60 元、售价 100 元，毛利 40 元、毛利率 40%、加价率约 66.67%。把“加价 40%”当成“毛利率 40%”会得到错误报价。赠品、返利、运费、退货和销售费用可能进一步降低贡献，毛利不等于最终利润。

**虚构渠道例：** 厂商供货 60 元，经销商批发 80 元，零售商售出 100 元。三者分别计算自己承担的成本与收入；经销商买卖差额 20 元、毛利率 25%，零售商差额 20 元、毛利率 20%，还各要承担对应仓储、人员、损耗和信用成本。终端售价不是厂商收入。

出厂价、供货价、建议零售价、实际成交价、到手价和结算价属于不同环节。平台抽佣、经销折扣、年度返利和联营扣点的计提基数可能不同；返利是否达到条件、退款如何冲回、谁开发票应按交易约定与实际责任判断。

### 3.3 折扣、促销与价格结构

促销可以拉新、处理库存、鼓励组合购买或填充低峰，但也可能提前透支需求、吸引只购买优惠的客户、损害渠道和培养等待折扣的预期。评估时看新增贡献与现金，不只看成交额。

**虚构例：** 单价 100、每单可变成本 60，原来每单贡献 40。打八折后单价 80、贡献 20；其他条件相同，要使总贡献持平，销量要翻倍。若新增订单又提高物流、人工或退款成本，翻倍仍可能不够；这不是降价必然带来两倍销量的预测。

阶梯价、会员价、组合、限时优惠、满减和返券可以服务不同客户与购买频次，应让条件透明。价格分层通常对应不同规格、数量、时间、权益或服务；个性化定价还涉及公平、告知与个人信息规则。预付会员卡带来现金和履约负债，不能直接视为促销利润。

**比较价格与折价基准。** 国内价格比较、折价和赠品标示应按[《明码标价和禁止价格欺诈规定》第 16～20 条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_9a1f82a007964950a1a0f6c056f2fedf.html)区分以下信息：

| 价格信息 | 含义与标示边界 |
| --- | --- |
| 实际成交价 | 对应交易条件下实际结算的价格；标价或划线价本身不能证明曾按该价成交 |
| 被比较价格 | 用来对照现价的价格，其信息必须真实准确；应能解释比较对象和依据 |
| 折价、减价计算基准 | 用来计算折扣或减价的价格；不得无合理理由临时显著抬高标价作基准，也不得采用无依据或无从比较的价格 |
| 厂商建议零售价 | 与之比较时须明确标示其性质，厂商建议发生变动应立即更新；不能混充本店历史成交价 |
| 赠品标价或价值 | 赠品须标品名、数量；若标价格或价值，应标其在同一经营场所的当前销售价格 |

**七日规则有特定条件：** 经营者**未标明被比较价格的详细信息**时，被比较价格应不高于该经营者在**同一经营场所、进行价格比较前七日内的最低成交价格**；前七日无交易时，应不高于本次比较前**最后一次交易价格**。这是该情形下的比较价格上限，不是一切促销统一使用的基准。已标明详细信息的比较，仍须真实准确并符合其他适用要求。

第 19 条还涉及低价诱骗后高价结算、虚假折价、误导标价、隐藏或显著弱化不利价格条件、无正当理由不兑现价格承诺、拒按约定折抵积分或券等行为。网络交易还须遵守第 20 条：首页或其他显著位置的标价不得低于详情页标价，公布的促销范围和规则须与实际相符；平台不得强制商家采用虚假或误导的价格标示。具体责任应结合交易事实和适用条文判断。

### 3.4 直销、经销、代理与多渠道

直销更直接理解客户和控制体验，但自担获取、配送、销售与售后；经销商买卖货品并承担约定库存/信用，代理更偏代表销售、撮合或提供渠道服务，实际法律关系取决于合同与行为，不能仅凭名称认定。

多渠道扩大覆盖，也带来同品不同价、线上线下冲突、窜货、重复获客、售后责任和信息断层。合理区分规格、服务和活动范围有助于解释差异；固定转售价或限定最低转售价可能涉及《反垄断法》第 18 条及其适用条件，不能把“维持渠道秩序”视为当然豁免。[官方依据](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_f0fae9eb3a684fc39e84d89eabfc2caa.html)。

## 4. 财务与现金：把经营事实表达清楚

### 4.1 先分清六类概念

| 概念 | 含义与典型内容 | 易混点 |
| --- | --- | --- |
| 资产 | 企业控制、预期带来经济利益的资源，如现金、应收、存货、设备 | 资产不一定能马上用于付款，存货可能卖不动 |
| 负债 | 过去事项形成、预计导致经济利益流出的现时义务，如应付、借款、预收履约义务 | 借款带来现金但也带来偿还责任 |
| 所有者权益 | 扣除负债后所有者享有的权益 | 注册资本、净资产、企业估值和银行余额不同 |
| 收入 | 日常活动带来的经济利益总流入，与所有者投入资本无关 | 签约、开票、收款和收入确认可能发生在不同时间 |
| 费用 | 经营活动中相应期间经济利益的流出或消耗 | 买设备、买库存、还借款本金不一定立即成为当期费用 |
| 利润 | 一定期间的经营成果 | 利润未必已收回现金，也未必可全部分配 |

权责发生制把收入与费用放到应属期间；现金口径看实际收付款。两者共同解释经营，不可只挑好看的一个。具体会计处理需采用适用准则，《企业会计准则》与《小企业会计准则》的适用和细节并不完全相同。[财政部基础定义](https://www.mof.gov.cn/zcsjtsgb/gztsgb/201407/t20140723_3578373.htm)。

### 4.2 三张报表和附注怎样联系

- **资产负债表：** 某个日期拥有什么、欠什么、所有者权益多少；是存量。
- **利润表：** 一个期间创造多少收入、消耗多少成本费用，形成多少利润；是期间成果。
- **现金流量表：** 同期经营、投资、筹资分别带来或消耗多少现金；是期间现金变化。
- **附注：** 解释确认方法、重要政策、结构、限制、承诺和异常事项；单看三表数字可能误读。

```text
资产 = 负债 + 所有者权益
期末现金 = 期初现金 + 经营现金净流量 + 投资现金净流量 + 筹资现金净流量
简化税前经营结果 = 营业收入 - 营业成本 - 对应期间费用
```

上面第三式用于本页管理算例，未完整列出会计利润表项目，不等于法定利润表填报公式。净利润还受财务费用、损失、其他损益及所得税等影响。经营管理中需要看可持续主业，不能靠出售资产或一次性补贴解释长期经营能力。

买设备先形成资产并按适用规则折旧，现金可能一次流出；应收增加可能利润上升而现金未到；采购存货先占现金，卖出时才按适用规则结转成本；融资进入现金流，不构成产品收入。经营、投资、筹资不是把所有流入都叫“营业额”。

### 4.3 收入确认、预收与平台总额/净额

经营者完成什么履约、何时转移控制决定收入确认；持续服务可能按符合条件的履约进度确认，一次商品交易可能在控制权转移时确认。签合同、收到预付款、收到发票或客户意向，不单独决定收入已经实现。

预收可能形成合同负债或适用准则下相应预收项目，直到交付；平台代收款、代收税或他人货款不自动成为自营收入。主要责任人/代理人的判断影响按总额还是净额确认：重点是交易前是否控制特定商品或服务，而不是平台到账是否扣了手续费。[财政部收入准则](https://www.mof.gov.cn/zcsjtsgb/gfxwj/201707/P020200907398079240429.pdf)。

**虚构持续服务例：** 客户预付 1,200 元取得 12 个月均匀服务，本例采用不含税金额、无退款，暂不计税款现金影响，假定收入每月确认 100 元；每月对应交付成本 40 元，年度服务贡献共 720 元，未扣获客和固定费用。首月收到 1,200 不表示首月收入 1,200；服务一个月后还有 1,100 的未交付销售部分与未来 440 的预算履约成本，这两个数含义不同。实际税务时点也需单独核对。

### 4.4 成本分类和盈亏平衡

**直接/间接**看能否归属具体产品或项目；**固定/可变**看相关期间和业务量范围内如何变动；**现金/非现金**看是否当期实际付款。三个分类维度不同。某工程师工资可直接归属项目，但短期仍是固定工资；计件外包可能是可变，设备折旧通常是非现金期间成本。

固定成本只在一定产能区间内相对固定；租第二个仓库会产生台阶。可变成本可能包括材料、运费、佣金、支付费、按单人工、耗材和用量服务。退货、坏货、保修、履约失败、客服与免费服务需要归属，不能因未即时发生就全当作零。

```text
单位贡献 = 同口径单位净收入 - 单位可变成本
贡献率 = 总贡献 ÷ 同口径净收入
单品盈亏平衡销量 = 期间固定费用 ÷ 正的单位贡献
稳定销售组合的盈亏平衡收入 = 期间固定费用 ÷ 正的加权贡献率
```

公式要求价格、可变成本、销售组合和产能区间基本一致，单位贡献为零或负时增加销量不能按这套模型覆盖固定费用。多品类不能随意拿最高贡献率代表全体；产能不到盈亏平衡销量时，问题可能在模式、价格或固定结构。

**虚构服务例：** 每单 300 元，材料 30、按单人工 100、交通 20，单位贡献 150；月固定费用 6,000，需要 40 单覆盖。若月可交付上限只有 30 单，即使全满仍差 1,500。这里人工设为按单可变；若工资已计固定费用，再加同一人工会重复扣成本。

### 4.5 税务和发票识读

税种、纳税人身份、交易性质、计税方法、优惠、地区与时期共同影响税款。增值税关注应税交易及计税，企业所得税/个人所得税关注相应所得，另外可能涉及消费税、附加、印花税等；税负不能只用一个“营业额乘税率”覆盖所有情况。

增值税法第 7～9、14～17 条区分价外税、一般/简易计税和进销项，第 21～22 条说明留抵与不得抵扣。以下仅用于理解金额，抵扣资格、凭证、免税、减免、混合业务与纳税时点按实际制度核对：[现行增值税法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5237365/content.html)。

```text
含税价 = 不含税价 ×（1 + 实际适用税率或征收率）
一般计税应纳增值税基本口径 = 销项税额 - 符合条件的可抵扣进项税额
简易计税基本口径 = 不含税销售额 × 实际适用征收率
```

**虚构税额识读例：** 假定一笔货物销售实际适用 13%，含税售价 113 元，则不含税销售额 100、销项税 13。假定同期相关采购不含税 60、进项税 7.8 且全部可抵扣，则简化应纳增值税 5.2；未计其他项目、调整、优惠或税种。把 113 当收入或把 13 全部当最终税负会误判利润。该例不是任何主体的税率建议。

**留抵与不得抵扣影响不同。** 一般计税下，当期可抵扣进项大于销项形成的留抵，可依第 21 条及国务院规定结转下期抵扣或申请退还；留抵不是当期收入，也不等于即时现金退回，现金预测须区分留抵余额、符合条件的退税申请与实际到账。第 22 条规定简易计税、免税、非正常损失、集体福利或个人消费等对应进项不得抵扣，取得专票不直接证明抵扣资格。不得抵扣的税额依交易性质和适用会计处理计入相关成本、费用或资产，影响利润的期间可能不同；会计归属可读财政部[《增值税会计处理规定》第二部分（一）第 2 项](https://kjs.mof.gov.cn/zhengcefabu/201612/t20161212_2479869.htm)，抵扣资格与操作仍按现行税制核对。

发票是交易与税务凭证，不等于付款到账证据，也不等于已经验收；收据、订单和支付记录各有作用。识读购销方、货物/服务、数量、金额、税额、日期、红字/作废与对应真实交易。退款、折让和退货还可能需要相应发票处理，不能用不真实内容“补一张票”。[发票管理办法](https://shanxi.chinatax.gov.cn/web/detail/sx-11400-545-1781492)。

会计收入、开票销售、税务销售额、平台成交与银行到账应能解释差异。实际税率、优惠期限、扣除和申报口径以税务机关现行规则为准，报价应提前说明含税及凭证安排；税额不应在收入和现金支出中无依据地重复扣。

### 4.6 预算、现金预测与现金跑道

预算是资源安排，预测是根据最新事实估计未来结果，二者不是同一件事。销售预算联动采购、人员、库存、投放、设备与现金；收入乐观却不给物流、退款和账期预算，会高估可用资金。

现金预测按实际到账、付款及到期义务逐期展开，包含平台结算、客户账期、工资、租金、税、退款、债务、资本开支与已售未交付承诺。基准、保守和压力情景要联动销量、价格、留存、采购和回款，不能只给收入任意乘一个折扣。

同样金额在不同时间收到，其资金价值不同：延迟收款需要垫资，并承担时间与信用风险。投资回收期帮助看何时收回投入，却不完整表达回收后的收益、期限和风险；较长期设备、门店或项目决策还要理解现值、净现值和所用折现假设。高账面回报与难以承担的前置现金可以同时存在。

```text
某期期末现金 = 期初现金 + 当期实际现金流入 - 当期实际现金流出
简化现金跑道 = 可用于经营的现金 ÷ 稳定且为正的每期净现金消耗
预测资金差额 = 各期（该期最低所需现金余额 - 该期预测可用现金余额）的最大值
本情景需补充资金 = max（0，预测资金差额）
```

跑道仅适合净消耗相对稳定、未遗漏到期大额支出的情景；预收集中到账、季节库存、账期、增长投入或债务到期时，优先逐期现金预测。可用于经营的现金要区分受限资金和应保留的确定义务；已有预收应评估未来退款与履约，不把银行余额全部视为可花利润。所需余额要按各期匹配比较，不能把发生在不同期的两个最低值直接相减；预测差额为负说明该情景有余量，仍需考虑预测误差。

#### 4.6.1 资金时间价值、NPV 与投入回收

现值把未来现金折算到同一个时点，净现值 NPV 汇总项目增量现金的现值后扣除初始投入。回收期重视资金多久回来，通常不完整考虑回收后的现金与时间价值；NPV 重视给定风险和资金代价下的整体现金价值，二者可相互补充。[OpenStax 原理](https://openstax.org/books/principles-finance-2e/pages/16-2-net-present-value-npv-method)。

```text
某期现金流现值 = 该期增量净现金流 ÷（1 + 每期折现率）^期数
NPV = 后续各期增量净现金流现值之和 - 初始投入
```

**虚构例：** 初始投入 10,000，每年末分别得到 6,000 的增量净现金，持续两年，假设年折现率为 10%，则两期现值约 5,454.55、4,958.68，NPV 约 413.22；在第二年末累计未折现现金超过初始投入。该折现率仅是教学假设，正的 NPV 不证明预测会兑现，也不解决回款前的资金缺口。

现金流应覆盖新增成本、税、营运资金、设备、维护及退出/残值，避免把会计利润直接代入；折现率与期间、币种、风险、税及融资口径应相容，不能用极低折现率掩盖不确定性，也不能无依据重复扣融资代价。寿命、回款、成本与折现假设变化可能改变选择。

### 4.7 营运资金、周转与信用

应收占用了已交付但未收到的钱；库存占用了尚未出售或使用的资源；应付提供付款时点缓冲但仍是义务。预收能改善现金时点，同时增加交付压力。增长常要求先增加存货、人员和应收，即使单笔有利润也会出现资金缺口。

```text
存货周转天数 = 平均存货 ÷ 同期销售成本 × 同期天数
应收周转天数 = 平均应收账款 ÷ 同期同口径赊销收入 × 同期天数
应付周转天数 = 平均应付账款 ÷ 同期同口径赊购额 × 同期天数
简化现金转换周期 = 存货周转天数 + 应收周转天数 - 应付周转天数
```

以上是管理分析口径，分子分母应匹配含税、业务范围及期间；数据不足而用营业收入或销售成本替代赊销/采购，应说明估算限制。季节性、预付款、预收、票据和重大期末波动会影响解释，负的现金转换周期也不免除履约或供应商付款责任。

**虚构周转例：** 同一 30 天期间的平均存货 60,000、销售成本 90,000，平均应收 120,000、同口径赊销收入 180,000，平均应付 75,000、赊购额 150,000；存货天数 20、应收天数 20、应付天数 15，简化现金转换周期 25 天。它说明采购到回款的资金占用机制，不表示所有订单都在第 25 天收到钱。

信用管理包括客户身份、信用额度、账期、账龄、逾期变化、担保、争议与催收。坏账是无法收回的损失风险，应与正常账期区分；企业名气、政府背景、口头承诺或发票已开，不直接证明一定按期到账。客户集中或单一平台冻结结算会放大现金风险。

### 4.8 虚构实物零售例：利润和现金同步读

假设本期发出 100 单，每单不含税销售 100 元；10 单全额退货，其中 8 件可重新销售，2 件损毁。货品单位采购成本 45、每个发出订单配送成本 10、退回每件成本 5；平台按退款后销售额收 5% 佣金，净结算下一期到账。本期固定费用 2,000，无获客费用。为专看经营，假设没有增值税和所得税现金影响。

| 当期管理口径 | 金额与依据 |
| --- | --- |
| 退款后净销售收入 | 9,000：发出销售 10,000，退款 1,000 |
| 已留存销售商品成本 | 4,050：90 件，每件 45 |
| 所有发出配送成本 | 1,000：100 单，每单 10 |
| 退回配送成本 | 50：10 件，每件 5 |
| 损毁货品损失 | 90：2 件，每件 45；与留存销售商品成本分开 |
| 平台佣金 | 450：退款后收入的 5% |
| 本期贡献 | 3,360；全部上述可变项目扣除一次 |
| 固定费用后经营结果 | 1,360；仍是本例简化结果 |

本期采购并支付 100 件货品 4,500，支付配送和退回成本 1,050、固定费用 2,000；佣金由平台下一期结算扣除，损毁是已付货品形成的非现金损失，均不再计本期现金付款。期初现金 10,000、本期流入 0、实付 7,550，期末现金 2,450；本期盈利而现金下降。

期末尚有平台净结算应收 8,550、可销售退货库存 360。无其他资产负债时，现金、该净结算应收与库存共 11,360，较初始资产增加 1,360，与本例经营结果一致。下一期仅收回 8,550、无新业务时现金变为 11,000，库存仍为 360；结算没有再次产生收入。正式账务中的应收与费用列示按适用准则处理。

## 5. 单位经济：找到业务实际计量单位

### 5.1 单位不必总是用户

| 业务 | 常用单位 | 必须覆盖的成本或风险 |
| --- | --- | --- |
| 零售、餐饮、电商 | 商品、订单、交易、门店、桌次 | 货品、包装、损耗、退货、物流、支付、佣金、门店固定能力 |
| 人工服务 | 工时、服务单、项目、可售时段 | 人员、材料、交通、空闲、返工、预约取消、管理与交付半径 |
| 企业销售 | 合同、项目、客户、续约周期 | 售前、试点、定制、交付、培训、支持、账期、坏账 |
| 数字与内容 | 付费客户、账号、席位、用量、授权 | 服务计算、内容授权、客服、免费使用、渠道、退款与持续维护 |
| 平台、经销与加盟 | 交易、合作商、网点、地区 | 撮合、保障、佣金、支持、信用、争议和区域管理 |

单位贡献为正说明该范围内有余量，仍需覆盖固定能力、获取客户及其他费用；单位贡献为负时规模通常放大问题，除非有明确、可支付的其他模式支持。必须先定义单位、期间、税、退款和成本归属，再比较不同业务。

### 5.2 CAC、客户贡献价值与回本

获客成本 CAC 指获得一批新客户对应的成本。分母可以是新增付费客户、首次订单或符合条件的合同，应明确命名，不能在不同渠道随意换成注册、粉丝、线索和成交客户。自然渠道也有内容、人员和维护投入，不自动是零成本。

```text
现金 CAC = 对应该批新客户的现金获客支出 ÷ 同口径新增客户数
全成本 CAC =（现金获客支出 + 对应非现金资源投入估值）÷ 同批新增客户数
观察期每名原始客户贡献 = 同批观察期贡献总额 ÷ 初始新增客户数
预测完整贡献 LTV =（从获客日起已观察贡献 + 尚未观察期预测贡献）÷ 初始新增客户数
贡献回本期 = 同批累计贡献首次覆盖同口径获客投入的期间
获客后贡献 = 同批服务/交易贡献 - 该批对应获客投入
```

本目录统一使用**贡献 LTV**，先扣约定范围的可变交付成本，尚未扣该批 CAC 与公司固定费用。完整生命周期预测包含未观察部分，必须标明假设、寿命、复购、流失、毛利变化和估值时点；观察期价值不能冒称完整 LTV。本页基础口径未折现，长期投资比较另需考虑资金时间价值。

分母为零时 CAC 无法计算，支出和损失仍存在。共享内容、品牌、免费服务或渠道费用应按合理口径分配一次，不能既在 CAC 又在交付贡献重复扣。关联费用与客户应匹配归因和时间；预算花在本期但合同下期才成交，不能直接混算。

**虚构数字持续服务批次：** 初始 100 名付费客户，现金获客 2,000、人工资源估值 600；现金 CAC 20、全成本 CAC 26。每名仍付费客户当期净销售 30、渠道费用 5.4、其他可变交付 5，单位贡献 19.6。另有按本例约定归属到此批的免费服务成本：

| 观察期 | 仍付费客户 | 关联免费成本 | 当期批次贡献 | 累计贡献 |
| --- | --- | --- | --- | --- |
| 第 1 期 | 100 | 900 | 1,060 | 1,060 |
| 第 2 期 | 80 | 360 | 1,208 | 2,268 |
| 第 3 期 | 60 | 180 | 996 | 3,264 |

三期每名原始客户已观察贡献 32.64，现金贡献回本发生在第 2 期，全成本贡献回本在第 3 期；扣除 2,600 获客投入后批次余量 664，还未覆盖公司固定费用。实际到账延迟可能使现金回本更晚，观察期之后是否仍有价值未知。

LTV/CAC、广告收入回报和毛利率各回答不同问题。没有跨行业通用的健康比例能代替客户批次、贡献、现金和风险分析；一次性耐用品、项目服务与持续订阅尤其不能直接共用流失或生命周期公式。

<a id="marketing-return"></a>

#### 5.2.1 ROAS 与营销 ROI：广告收入回报不等于盈利

ROAS 表达广告支出对应多少归因价值，ROI 表达明确定义投入带来的净收益。平台可能把“转化价值”配置为成交额、收入、毛利或估值；同名 ROAS 也可能口径不同，百分数和倍数更要统一。[平台定义与转化价值说明](https://support.google.com/google-ads/answer/13064207?hl=en-EN)。本目录作经营比较时采用以下明确口径：

```text
收入 ROAS = 同口径广告归因净成交收入 ÷ 广告支出
活动增量贡献 = 活动带来的增量净收入 - 对应增量交付成本（尚未扣营销投入）
活动营销后净收益 = 活动增量贡献 - 活动新增非营销固定成本 - 该活动全部营销投入
营销活动 ROI（增量经营收益口径）= 活动营销后净收益 ÷ 该活动全部营销投入
```

**虚构例：** 广告支出 2,000，归因净成交收入 10,000，收入 ROAS 为 5 倍（500%）。假设这笔收入全部是活动增量，对应交付成本 7,500，素材与活动人工另花 1,000，总营销投入 3,000，无新增非营销固定成本；活动增量贡献 2,500、营销后净收益为 -500，ROI 约 -16.67%。高收入 ROAS 可以与亏损同时存在。

归因说明平台如何分配成交，增量说明相对于未开展活动增加多少；两者不同。若没有可靠增量证据，只能把收入 ROAS 和假设情景分开报告，不把归因成交全算成活动净收益。退款、税、渠道扣费、观察期、自然成交、交付成本、固定能力新增及重复成本都需处理；分母为零时比值无定义，利润与现金回本另看前文口径。

### 5.3 产能、客户结构与规模

平均客户成本可能掩盖退货高的渠道、过度定制的企业客户、重度使用的数字客户或远距离服务单。成本不仅跟人数变化，还跟购买频次、SKU、距离、时段、异常和服务范围变化。

产能利用率提高能够摊薄部分固定费用，但持续接近满负荷可能增加等待、故障与返工。扩张后要观察新增贡献是否覆盖新增管理和能力台阶，以及资金是否在回本前充足；总量增长不自动证明边际经营改善。

<a id="transactions"></a>

## 6. 商务交易：从需求到收款与持续关系

### 6.1 销售与商务的完整链条

销售把明确价值转化为可履行交易；商务还包括渠道、伙伴、采购、资源及条款协商。完整链条通常经过需求与资格判断、决策链、方案、报价、谈判、合同、交付验收、开票结算、回款、售后续约。行业可合并部分环节，但不能省略对应责任。

ToC 往往由同一人快速决策，也会受家人、门店人员和评论影响；ToB 通常有使用者、业务推动者、预算持有人、技术/安全、采购、财务与签约授权人；ToG 还涉及预算、采购制度和公开程序。与单个联系人关系良好，不等于采购条件已经成立。

线索、商机、报价、采购意向、签约、交付、确认收入、回款属于不同状态。销售预测可以表达概率和预期日期，但必须把事实、推断和承诺分开；销售激励若只看签约额，会鼓励低利润、难交付或收不回的钱。

### 6.2 报价和采购比较

报价应说明主体、规格/服务范围、数量、单价、税、运费、安装、周期、验收、维护、付款、有效期及变更。客户采购关心的不只有报价：适用性、可靠性、交付、资质、总持有成本、供应连续性、售后和内部风险都影响选择。

采购决策同样看供应商总成本，而非最低标价。便宜的原料可能带来损耗、延期、返工、库存或质量责任；供应商强加独家、预付、最小采购量、不可迁移数据或长期最低消费，也会改变真实代价。

**虚构机构项目例：** 不含税合同收入 100,000，售前投入 5,000、交付与支持可变成本 55,000、固定资源分摊 20,000，本例经营余量 20,000。若仅收到签约预付 20,000，交付成本先全部支付，回款前至少需要另行覆盖 35,000 的交付现金差额；售前和固定现金支出还需按时点加入。利润 20,000 不能直接支付尚未到账的工资。

### 6.3 谈判中的利益、替代和边界

立场是“我希望价格多少”，利益是预算、交期、风险、现金或业务结果。双方可交换价格、数量、周期、付款、范围、授权、服务、独家与风险承担；某项低成本但高价值的条件，可能比双方反复压价更有用。

**BATNA** 是谈不成时最佳可行替代；**保留条件**是可以接受的最低整体组合；**ZOPA** 是双方可接受条件存在交集的区域。替代必须能实际执行，不是虚报的筹码。没有交集时可以改变范围、等待或停止，已花谈判时间不是必须成交的理由。[谈判方法来源](https://www.pon.harvard.edu/category/daily/batna/)。

谈判权来自可替代性、信息、时间和可信履约能力。底线要把税、资金、库存、违约与机会成本一起考虑；谈判中未经授权承诺折扣、交期或数据开放，会把局部成交变成整体风险。

### 6.4 合同、变更与交付

合同把双方权利义务确定下来。要理解主体与权限、标的/范围、质量、价款、付款条件、交付、验收、保密、知识产权、数据、变更、违约、解除及争议解决的作用。口头、邮件、订单和电子记录可能产生法律效果，不能认为“没盖章”就一定不存在责任。

格式条款涉及提示、说明和效力边界；补充协议、需求变更、订单和验收证据应能相互对应。定制、承揽、买卖、租赁、委托等合同的规则与风险分配不同，模板标题不能代替交易性质。[《民法典》合同编相关条款](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5212250/content.html)。

验收应对应可证明交付的标准与期限，不能无限挂起；范围扩大应联动价格、交期与资源。售后、保修、维护、服务等级、响应和解决时间含义不同，“随叫随到”可能需要额外值班能力。违约金约定、损失和可执行责任需按法律及实际证据理解。

### 6.5 对账、回款与售后

对账连接订单、发货/服务、验收、退货、发票、扣费、应收与银行；每一笔差异可能来自时点、退款、返利、代扣、争议或错误。平台结算报告不必等于银行到账，也不直接等于收入。

回款管理要明确付款到期、验收触发、资料、异议、催收和信用额度。商业汇票、应收账款电子凭证等非现金工具需要理解到期、贴现、追索与现金可用性；收到工具不等于收到银行现金。

《保障中小企业款项支付条例》按适用主体对付款、验收和非现金安排作规定，机关事业单位与大型企业的规则有差别；相关合同不能简单把“最终客户给钱后再付”作为当然可用条件。具体适用、起算和例外看第 2～3、9～11 条。[工信部现行条例](https://www.miit.gov.cn/jgsj/zfs/xzfg/art/2025/art_d9b6cd05f3734869aa34caff247089ff.html)。

售后既处理缺陷，也提供复购与产品改进证据。退款、返工、赔偿、召回和争议需要责任与预算；忽视投诉可能把小额交易演变为更高成本的法律、口碑和经营问题。

### 6.6 合作尽调、经销与政府采购

尽调关注对方主体与授权、资质、信用、履约、资金、权益、受众/客户匹配、实际资源和历史争议。国家企业信用信息公示、官方许可和采购公告可核实部分事实，但登记存在不直接证明质量、偿付能力或商业承诺可靠。

渠道合作需要理解铺货与终端动销、退换、返利、培训、账期、区域、数据、售后和退出；向渠道发货只是链条的一步。联营要区分谁收款、谁开票、谁管理和谁担责；加盟要看经营支持和独立盈利，商业特许经营还需按实际关系核对专项制度。

政府采购法对适用范围、供应商资格、程序与合同作规定；国企采购不因“国企”身份就全部等同政府采购，工程项目还可能涉及招标投标制度。具体目录、限额、预算、采购文件、评分和质疑渠道按实际地区项目核对。围标串标、虚假材料、商业贿赂不能成为取得订单的办法。[政府采购法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_47b5807c40c040368eb5f13b489d6c43.html)。

<a id="operations"></a>

## 7. 供应、履约与经营能力

### 7.1 采购、库存与供应连续性

采购连接需求预测、订单、合同、到货、检验、入库、付款和供应商评价。采购量越大可能单价更低，同时增加库存、保管、过期、损耗和资金占用；最低单价不一定是最低总成本。

库存有原料、在制品、成品和备件等形态。安全库存缓冲需求与供应波动，过量库存则占现金、掩盖滞销；补货点受交付周期、需求波动和服务目标影响。销量预测应考虑季节、促销、渠道压货、退货和新品不确定性。

周转快也可能经常缺货；库存多不表示资产质量好。长尾 SKU 增加采购、仓储、展示、退货和管理复杂度；商品损耗、过期、价格下降和可销售性影响真实价值。供应商集中、单一关键原料或专有接口都需要替代与恢复能力。

### 7.2 产能、质量与交付

产能是某些约束条件下可以稳定兑现的输出，不只是理论最大值。瓶颈可能在原料、设备、人、审核、安装、客户配合或售后；增加非瓶颈资源未必提高产出。服务业还受路程、时段、预约、技能和返工约束。

标准化降低差异与成本，定制提高适配但增加售前、审批、维护与知识依赖；流程应保持能检查的质量点和异常处理。短期压缩质检、培训或客服可能改善账面费用，同时增加退货、返工和声誉损失。

物流包括出库、运输、签收、安装和逆向退货；偏远地区、冷链、易碎、高价值和危险品的成本结构不同。线上承诺的时效与配送范围要由真实能力支持；线下连锁还需要门店、仓和人员的协调。

### 7.3 风险、保险与经营退出

经营风险包括需求、价格、供应、质量、人员、资金、信用、合规、安全、自然灾害、系统故障和声誉。风险管理通常组合预防、降低、分散、转移和接受，不能把买保险等同全部转移。

保险关注保障对象、触发、除外责任、免赔额、限额、证据和通知义务；产品责任、公众责任、财产、运输等是否合适取决于实际业务。客户合同可能要求特定保障，但保单不自动覆盖所有违约或经营损失。

退出、停业或迁移仍需处理库存、租约、员工、借款、应收应付、客户预付、售后、数据、许可和知识产权。停止新业务不代表旧义务消失；退出价值和退出成本是商业选择的一部分。

<a id="organization"></a>

## 8. 组织、公司、股权与融资

### 8.1 组织分工和经营管理

目标应连接客户价值、贡献、现金与履约，随后分配资源、责任和权限。战略说明服务谁、提供什么价值、怎样竞争以及取舍；计划连接资源与动作，预测反映未来判断，三者不应只是一组增长数字。

一人可以兼任产品、销售、交付和财务；重要的是谁能承诺、谁验收、谁付款、谁对账。授权边界与适当复核降低误承诺、漏账和利益冲突；组织变大后靠口头记忆管理会失效。

目标管理、过程检查与经营复盘的作用，是发现偏差和调整资源。指标应成组解释：销售额看规模、贡献看收益、现金看生存、交付和投诉看兑现。只考核单个数字容易产生刷销量、延迟退款、压库存或超售。

### 8.2 人员、外包与激励

招聘与外包需要匹配任务、能力、管理和交付。外包可以获得专业能力，也会增加接口、质量、保密、数据和成果权属问题；内部人员也需要培训、交接和制度，不能把长期能力完全寄托在单个人身上。

工资、奖金、佣金、利润分成、股权和期权含义不同：现金报酬解决当期劳动与激励，股权涉及长期风险、控制、退出和不确定价值。激励应兼顾贡献、质量、回款和长期客户关系，规则不明会造成争议和短期行为。

劳动关系依据实际事实和法律判断，不能仅用“合作”“外包”“实习”等名称规避义务。书面劳动合同、工资社保、工时休息、安全、试用、解除和补偿都有具体要求；服务采购与雇佣也有不同责任。[劳动合同法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_0abfdd261c03417b949df19d869add8d.html)。

### 8.3 公司、股权与治理

个体工商户、个人独资、合伙与公司在责任、出资、税务、治理和适用条件上不同。“注册一个公司”不直接证明业务值得做，也不能替代行业许可；主体选择取决于责任、伙伴、融资、客户采购与实际经营需要。

公司资产与股东个人财产应区分，有限责任存在法定边界和例外；法定代表人、股东、董事和经理并非同一个角色。股权比例也不自动等于全部表决权、职位、工资或可立即兑现的财富，实际还受法律、章程和协议影响。

注册资本是出资承诺，不是公司估值或现金余额。《公司法》第 47 条对有限责任公司认缴出资期限作规定，既有公司和特殊情况需要核对过渡及其他适用规定；第 54 条涉及不能清偿到期债务时的加速出资情形。[现行公司法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5233383/content.html)。

合伙与股权安排要理解投入、职责、决策、利润、知识产权、未来融资、转让、离开、僵局与争议。把口头“大家平分”当作完整治理，会在贡献变化、缺钱和退出时暴露问题；国外归属期或投资文件不能未经适配直接用作国内法律安排。

### 8.4 融资、债务和稀释

自有资金、经营积累、股权、借款、融资租赁及供应链资金工具有不同来源、代价与限制。融资现金帮助承担投入与时点缺口，不能当销售收入，也不能证明模式已验证。债务通常要求偿还与利息，股权涉及所有权和治理，担保还可能扩大个人或关联主体风险。

```text
简单单轮投后估值 = 投前估值 + 新增投资额
同口径新增投资者比例 = 新增投资额 ÷ 投后估值
原股东投后比例 = 原股东投前比例 ×（1 - 新投资者比例）
```

**虚构例：** 投前估值 800 万、新增投资 200 万，投后 1,000 万、新投资者持股 20%，原持股 60% 的股东变为 48%。仅适用于简单同权新增股权、无其他变化；期权池、老股转让、优先权、转换、估值调整等会改变结果。估值高不等于可以自由支配同等现金。

融资要理解资金用途、现金需求、偿还来源或成长预期、控制、优先权、对赌/回购、限制和退出；投资条款的经济与法律效果要一起读。大量融资后仍可能因成本、回款和组织能力失控，扩张的依据应是经营证据与兑现能力。

## 9. 国内经营法律：理解责任怎样随行为发生

### 9.1 主体、地区、行业和交易性质

法律适用首先取决于实际行为、主体、客户、商品/服务、地区和角色。市场主体登记、行业经营许可、产品强制标准、平台准入是不同要求；营业执照经营范围、平台审核或备案不能单独证明所有业务都可开展。

全国性规则提供基础，各地登记、许可、采购限额、劳动、税务操作及行业主管要求可能有细节。港澳台、跨境交易和数据出境需另查对应制度。食品、医疗、教育、金融、运输、建设、互联网信息服务等有特别条件，应由具体功能与行为触发核对。

### 9.2 消费者、安全、宣传与价格

消费者权益涉及知情、选择、公平交易、安全、质量、凭证、售后和争议处理。免费、赠送或试用不必然免除安全责任；宣传、销售页、店堂说明和合同中的承诺可能影响实际义务。

七日无理由退货有适用交易方式、商品类别、确认与完好等条件，不能泛化为所有服务都可七日退款，也不能自行把全部商品列为例外。预付涉及服务履行、退款和经营变化；自动续费应按条例第 10 条的时点显著提醒。具体看[消费者条例第 7～13、17、19、21～24 条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2024/art_0aea188276a44f0baf940ab95ee00e0a.html)。

广告与商业宣传要真实、可证、可识别，价格、优惠和赠送条件应清楚；代言、医疗/药品/保健食品等有特别边界。销量、用户评价、效果、荣誉、资质和对比不能捏造，付费推广不能因采用“分享”形式就自动免除相应责任。[广告法指定条款](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)。

### 9.3 知识产权、成果与秘密

著作权保护符合条件的作品，商标保护相应标识权益，专利保护依法授权的技术/设计方案，商业秘密保护符合秘密性、价值和保密措施等条件的信息。它们适用的对象、取得方式、期限与权利范围不同。

素材可下载、网页可查看、注明来源、域名可注册或名称未被平台占用，都不直接证明有商用权。许可需看商业使用、复制、修改、传播、地区、期间、转授权与署名；委托和职务成果需按法律和合同判断，付钱外包不自动取得所有权利。

专利新颖性与公开时点有关，商标要看类别和近似冲突，商业秘密需要实际保密措施；开源、用户上传和供应商内容也各有边界。具体制度和阅读范围见 [README 的知识产权条款](README.md#33-消费者传播竞争知识产权与数据)，当前商标用现行文本，已公布未生效的修订不能提前混用。

### 9.4 个人信息、数据与电商角色

门店登记、员工管理、客户联系人、配送、会员和数字服务都可能处理个人信息。先看必要性、目的、处理基础、告知、保存、访问权限、委托/提供、删除与请求处理；同意不是唯一合法基础，也不等于可以无限收集和用途变更。

敏感信息、未成年人、自动化决策、公开或对外提供、出境有特别要求，委托第三方不免除自己的相关责任。匿名化与简单去标识不同；公开联系方式也不自动意味着可任意采集、出售或营销。[个人信息保护法指定条款](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。

电商卖家、平台、自营、信息中介和物流有不同义务；谁签约、收款、交货、保管信息与处理售后需要明确。电商法有适用范围与排除，第 27～38 条等平台要求不应全部硬套给普通卖家；线上交易还可能受消费者、广告、数据和行业法规共同约束。[电子商务法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_14453aa523094819aa8f1d4530ce3cc4.html)。

### 9.5 竞争、信用与廉洁交易

混淆标识、虚假宣传、刷单评价、商业贿赂、侵犯秘密、诋毁、违规有奖销售和不当网络行为均可能损害交易秩序。合法折扣、佣金需明示并真实入账，不能用“返点”掩盖对采购人员个人的贿赂。[2025 修订反不正当竞争法第 7～15 条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3737890d856a4e44a8ea07c50c90c116.html)。

同行协商固定价格、分配客户、串标，渠道限定最低转售价、排他安排和并购，可能涉及不同竞争制度及适用条件。反垄断不只针对“最大的公司”；不能通过行业协会、算法或合作协议包装违法行为。具体是否违法、是否适用例外，需要市场和交易事实判断。[反垄断法第 16～26 条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_f0fae9eb3a684fc39e84d89eabfc2caa.html)。

### 9.6 查证方式和责任闭环

经营知识的作用是识别问题、解释事实和理解专业意见。规则查证要确认发布机关、现行版本、生效/废止、主体范围、行为条件和例外；征求意见稿、平台建议或培训资料不是现行法律本身。

重大、复杂或不明确的税务、用工、合同、融资、资质和数据事项，专业判断需要真实主体、交易、资金与行为事实。法规、合同、订单、验收、发票、支付、投诉与授权记录应能连接，责任不因学习结束、渠道合作或停止销售就自动消失。
