# VS Code Recommended Extensions

这是一个 VS Code 工作区推荐插件配置，覆盖：

- Web 前端
- 微信小程序
- Flutter / Dart
- Python
- 通用开发效率工具

## 使用方法

把 `.vscode/extensions.json` 放到你的项目根目录，例如：

```text
your-project/
  .vscode/
    extensions.json
```

然后用 VS Code 打开项目，VS Code 会提示安装推荐插件。

也可以打开扩展面板，搜索：

```text
@recommended
```

查看当前项目推荐安装的插件。
