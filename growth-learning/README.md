# 运营推广：理解市场，让价值被发现并持续兑现

[三领域共同导航](../product-learning/README.md) · [知识正文](knowledge.md) · [经营判断与案例](design.md) · [商务商业](../business-learning/README.md)

本主题面向中国大陆的通用产品与市场：实体商品、数字产品、服务，ToC、ToB、ToG，全国、区域、本地以及线上线下。内容采用知识讲解、案例和外部阅读，不设练习、作业、填写模板或学习验收，也不以某个 App 为主线。

“通用”表示能迁移的概念和判断，不表示所有行业适用同一获客渠道、推广话术、复购窗口或法律规则。食品、医疗、金融、教育、预付、政府采购等专项内容，应结合[商务商业知识](../business-learning/knowledge.md)和相应官方制度理解。

## 2. 理论教材：具体章节与阅读范围

下表的范围均指概念正文、模型说明和示例；章末问答、练习、项目、认证及产品推销内容可以跳过。原有官方章节目录与公开页面于 **2026-09-30** 核对；新增第 18.3 节的指定范围于 **2026-10-01** 核对。

微信公众平台、企业微信、淘宝天猫、京东、拼多多、快手及美团等在知识正文中作为可能的经营场景出现，不据此声称已核验其全部最新规则。微信、淘宝部分官方页面本次自动读取受限，未用转载文或非官方经验替代规则；实际采用时从平台官方后台核查主体与行业准入、商业合作、外链、消息发送、交易、评价和售后对应条目。
